# Touch-Dan 验证范围

Touch-Dan 当前处于 0.1.0 开发阶段。最后一次本机 RootHide 构建已通过，并在 iPhone15,2 / iOS 16.0.2 / RootHide 上完成安装替换、组件加载、隐根图片保存与偏好落盘核验。iOS 17 及下表列出的交互场景仍待验证。上游的系统支持范围不是本分支的测试结果。

## 已完成的主机逻辑检查

| 检查 | 本机结果 | 验证范围与限制 |
| --- | --- | --- |
| 生命周期 | 32 项通过 | 提取生产方法体，以 Foundation 模拟对象检查状态转换及清理；不验证 UIKit 渲染或系统触摸 |
| 路径 | 42 项通过 | rootful 6 项、rootless 6 项、RootHide 30 项；使用真实符号链接夹具与模拟路径提供者，三个方案的公共头均编译通过 |
| 图片文件 | 通过 | 实际生产文件操作覆盖无效目录拒绝、同目录暂存、图片缓存区分、受限清理、权限失败及重置；UIImage 为占位对象 |
| 偏好设置 | 63 项通过，1 项主机 UNVERIFIED | 生产实现与实际预设的写入保护、状态及通知检查；主机隔离环境未确认绝对 suite 落盘，该项另在下述 iOS 16.0.2 真机核验通过 |

复现命令：

```sh
python3 Tests/run-lifecycle-tests.py
python3 Tests/run-path-tests.py
python3 Tests/run-image-storage-tests.py
python3 Tests/run-preferences-tests.py
```

偏好测试在隔离的主机进程中运行，限制文件写入并禁止连接 cfprefsd。未观察到明确的 plist 落盘，因此将该项标记为 `UNVERIFIED`；不能因为 `synchronize` 返回成功就认定保存通过。添加 `--require-persistence` 可将未确认落盘视为失败。这些检查不验证 iOS 偏好服务、跨进程设置共享或真机文件输出位置。

RootHide 路径检查会拒绝空值、相对路径、原系统路径回退、错误越狱标识及逃逸符号链接；允许当前主隐根，以及经回链核验的同标识第二隐根 `/var`。图片检查确认插件控制的暂存文件与最终文件位于同一目录。主机检查不能证明 iOS 系统服务内部从不使用真实 `/var/tmp`。

本次修复包括：录屏/便捷访问临时隐藏后恢复用户选择的拖尾、形变和轨迹；结束/取消的触摸不再维持活动状态；关闭显示时结束 QuickPath、停止形变计时器、取消清理任务并移除触摸标记；空录屏回调及没有窗口场景时安全关闭；静止时停止无触点的清理轮询；所有 UIWindow QuickPath 扩展方法使用独立前缀。以上逻辑检查不代表系统运行场景全部通过。

## 已完成的 iOS 16.0.2 真机核验

设备型号为 iPhone15,2，使用 RootHide。原 Touch-Viz 4.1.1 已备份到电脑，经 dpkg 移除后安装 Touch-Dan 0.1.0，并执行 sbreload。观察到 SpringBoard 稳定加载 `TouchDan.dylib`，设置进程加载 `TDNPrefs`。

| 核验项 | 实际结果 |
| --- | --- |
| 图片保存与旧图清理 | 通过生产 NSBundle 方法先后保存两张包内默认图到 `<当前第二隐根>/var/mobile/Library/Touch-Dan`；第二次保存并清理后只保留第二张 |
| 偏好实际落盘 | 绝对 suite 写入 `<当前第二隐根>/var/mobile/Library/Preferences/io.github.suckdrygod.touchdan.plist`；将设备文件下载到电脑，用 `plistlib` 读取确认数据 |
| 设置跨进程读取 | SpringBoard 读取到与设置端一致的启用状态、测试尺寸 27 和所选图片；主机未确认的落盘项在本次 iOS 16.0.2 环境得到验证 |
| 真实系统目录检查 | `/rootfs/var/mobile/Library` 下没有 Touch-Dan 图片目录、同名偏好文件或安装缓存；真实 `/rootfs/var/tmp` 递归检索未发现本插件名称、包标识或两张测试图片 UUID 的残留 |
| 测试收尾 | 已删除两张测试图片及图片目录，清理全部安装暂存；重置为“清晰触点”、尺寸 26，并开启总开关供查看 |

真实 `/rootfs/var/tmp` 的前后顶层条目对比为 `added=[]`、`removed=[]`。七项既有系统目录或现有 ios-mcp 日志的元数据发生更新，因此不能表述为该目录完全未变化。本次检查未发现插件残留；前后快照也不能证明系统服务在期间从未产生过短暂文件。

公开记录使用“当前第二隐根”表示设备生成的目录，不公开随机越狱标识、设备唯一标识或个人数据。以上结果限于本次设备与系统环境，不代表 iOS 17 或全部交互场景通过。
